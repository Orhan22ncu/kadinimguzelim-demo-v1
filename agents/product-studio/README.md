# AI Product Studio — Content Agent

Defines the agent that writes KadınımGuzelim product content. Given a product's
**identity + imagery**, it generates the premium Turkish copy that powers both the
human-facing PDP and the machine-readable `/products.json` feed.

## What it produces (per product)

From input (`title` seed, `category`, primary `image` URL, `colors`, `sizes`, `price`)
the agent generates a structured object:

- `title` — polished product title
- `description` — 2–3 sentence premium Turkish description
- `fabric` — `{ doku, esneklik, transparanlik, dantel, kalip, icerik }`
- `callouts` — 3–4 image detail labels (e.g. "Fransız Dantel")
- `seo` — `{ title, description }`
- `tags` — search/SEO tags

## How it works

- **Model:** Claude Opus 4.8 (`claude-opus-4-8`) — high-resolution vision reads the
  fabric/lace/stitch detail from the product image; strong Turkish copy.
- **Structured output:** `output_config.format` (JSON schema) so every field is
  valid and directly writable to the feed — no parsing.
- **Prompt caching:** the brand-voice + taxonomy system prompt is cached, so each
  product reuses the stable prefix cheaply.
- **One-time generation:** runs in the content pipeline (build/ingest), never in the
  page request path. Output is committed to `products.json`.
- **Human review gate:** the agent proposes; a human approves before publish. In this
  category an inaccurate "şeffaf değil" or overstated "Fransız danteli" claim erodes
  trust — never auto-publish.

## Run

```bash
cd agents/product-studio
npm i @anthropic-ai/sdk
export ANTHROPIC_API_KEY=...        # or `ant auth login`
node product-studio.mjs             # reads seeds, writes ../../products.json
```

> The current `products.json` was generated by this agent (Claude Opus 4.8) and
> human-reviewed. Re-run to regenerate or to scale to the full catalog (see the
> sitemap-driven scrape in the project roadmap).

## Scaling to the live catalog

`https://kadinimguzelim.com/sitemap/products/0.xml` lists ~1000 products. The next
phase feeds product slugs → fetches identity (og:title, images, category) → runs this
agent per product → writes the feed. Respect `robots.txt`; rate-limit requests.
